# Editando Imagens com Array

![Python](https://img.shields.io/badge/Python-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Status-Concluído](https://img.shields.io/badge/Status-Concluído-brightgreen?style=for-the-badge&logoColor=white)

Edição de imagens com Numpy e OpenCV.

---
## 📚 Aprendizados
- Função np.zeros da biblioteca Numpy
- Funções putText e imwrite da biblioteca OpenCV

## ⚙️ Funcionalidades
- Modificação de imagens
- Criação de imagens com array

## 🛠️ Stack
- Python
- OpenCV
- Numpy

## 🚀 Deploy
1. Clone ou baixe este repositório.

```bash
git clone https://github.com/BiaHashi/Imagem_com_Array
```

2. Abra os arquivos ".py" e execute-os no VS Code.
